APEXIQ V0.2.18 — PRODUCTION TAILWIND PACKAGE

1. Extract this folder.
2. Double-click START-HERE.cmd.
3. The script automatically downloads the official Tailwind CSS standalone CLI if it is not already present.
4. It compiles css\input.css into css\output.css.
5. ApexIQ then opens locally.

You do NOT need to install Node.js or npm for this build path.

For deployment, upload the project only after css\output.css has been generated.
Do not delete the Tailwind executable if you want to rebuild CSS locally later.

The package preserves the V0.2.18 workspace-switch-fixed application logic. No V0.3 features were introduced.
